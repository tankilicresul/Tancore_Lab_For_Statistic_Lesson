The code should update based on the selected simulation.

Default Python code for logistic regression:

import numpy as np
import pandas as pd
import matplotlib.pyplot as plt
from sklearn.linear_model import LogisticRegression
from sklearn.metrics import accuracy_score, confusion_matrix

np.random.seed(42)

X = np.linspace(-20, 20, 500).reshape(-1, 1)
probability = 1 / (1 + np.exp(-0.25 * X))

y = np.random.binomial(1, probability.ravel())

model = LogisticRegression()
model.fit(X, y)

predictions = model.predict(X)
accuracy = accuracy_score(y, predictions)

print("Accuracy:", accuracy)
print(confusion_matrix(y, predictions))

The code does not need to execute on a backend in the first MVP. However, the UI should feel ready for future code execution.

DATA GENERATION:
Generate synthetic data in the frontend.

Linear regression:
y = slope * x + intercept + noise

Logistic regression:
p = 1 / (1 + exp(-(slope * x + intercept)))
y = Bernoulli(p)

Normal distribution:
Generate random values around mean and standard deviation.

Hypothesis testing:
Generate two sample groups and calculate mean difference, p-value placeholder, and confidence interval.
